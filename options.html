How to get an API key

OpenAI Anthropic (Claude)
  1. Go to platform.openai.com and sign up or log in
  2. Navigate to API Keys in your dashboard
  3. Click "Create new secret key", give it a name, and copy the key
  4. Paste the key above and click Save — Dobby AI will validate it automatically

OpenAI keys typically start with sk-. You'll need a payment method on your OpenAI account. Usage is billed per request (~$0.001/question with GPT-4.1-mini).

  1. Go to console.anthropic.com and sign up or log in
  2. Navigate to API Keys in Settings
  3. Click "Create Key", name it, and copy the key
  4. Paste the key above and click Save — Dobby AI will validate it automatically

Anthropic keys start with sk-ant-. Note: Dobby AI currently uses OpenAI for all features. Anthropic key support is planned.
